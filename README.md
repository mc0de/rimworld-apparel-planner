# RimWorld Apparel Planner

A single-page planner for comparing RimWorld apparel across materials and quality levels: armor, insulation, comfortable temperature range, and expected damage per body part against common weapons.

Live: https://mc0de.github.io/rimworld-apparel-planner/

Data comes from the RimWorld Core defs (v1.6.4871). DLC items aren't included.

Icons are loaded from the [RimWorld Wiki](https://rimworldwiki.com/) when the page opens. RimWorld and its art belong to Ludeon Studios. If an icon can't load, the page shows the material's color instead.
